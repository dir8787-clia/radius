# Установка FreeRADIUS с daloRADIUS веб-интерфейсом

Этот проект содержит автоматизированный скрипт для установки и настройки FreeRADIUS с daloRADIUS веб-интерфейсом на Debian 11/12.

## Описание

Скрипт автоматически устанавливает и настраивает следующие компоненты:

- **FreeRADIUS** - сервер аутентификации RADIUS
- **MariaDB** - база данных для хранения информации о пользователях
- **Apache** - веб-сервер для daloRADIUS
- **PHP** - язык программирования для веб-интерфейса
- **daloRADIUS** - веб-интерфейс для управления пользователями RADIUS

## Особенности

- Полностью автоматизированная установка
- Безопасная настройка MariaDB
- Автоматическая настройка SQL поддержки в FreeRADIUS
- Импорт всех необходимых SQL схем
- Создание случайных надежных паролей
- Вывод учетных данных после установки
- Поддержка брандмауэра UFW

## Требования

- Debian 11 или 12
- Права root
- Подключение к интернету

## Использование

1. Сделайте скрипт исполняемым:
   ```bash
   chmod +x install_freeradius_daloradius.sh
   ```

2. Запустите скрипт от имени root:
   ```bash
   sudo ./install_freeradius_daloradius.sh
   ```

3. После завершения установки скрипт выведет учетные данные для доступа к системе.

## Доступ к веб-интерфейсу

После установки веб-интерфейс daloRADIUS будет доступен по адресу:
```
http://ВАШ_IP/daloradius
```

## Учетные данные по умолчанию

- **Пользователь daloRADIUS**: administrator
- **Пароль администратора**: будет сгенерирован случайно
- **Тестовый пользователь RADIUS**: testuser
- **Пароль тестового пользователя**: testpass

## Сервисы

- **FreeRADIUS**: запущен и включен автозапуск
- **Apache**: запущен и включен автозапуск
- **MariaDB**: запущен и включен автозапуск

## Порты

- **1812/UDP**: RADIUS Authentication
- **1813/UDP**: RADIUS Accounting
- **80/TCP**: HTTP веб-интерфейс

## Безопасность

Скрипт автоматически:
- Настраивает безопасность MariaDB
- Создает уникальные пароли для каждой службы
- Открывает только необходимые порты в брандмауэре
